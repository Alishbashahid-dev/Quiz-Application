#  Quiz Application

A simple console-based quiz application built in C++ that tests general knowledge across multiple topics.

##  About

This project was developed as part of my Programming Fundamentals course. It presents multiple-choice questions to the user and calculates the final score at the end.

##  Features

- Multiple choice questions (A/B/C/D format)
- Real-time feedback on each answer
- Final score display at the end
- Case-insensitive input handling

##  Built With

- C++
- Standard I/O (iostream)

##  How to Run

1. Clone the repository
```bash
   git clone https://github.com/Alishbashahid-dev/Quiz-Application.git
```
2. Compile the code
```bash
   g++ quiz.cpp -o quiz
```
3. Run the program
```bash
   ./quiz
```
